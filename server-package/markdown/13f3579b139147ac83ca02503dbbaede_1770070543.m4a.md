# Meeting Summary

## Topic Discussed
- Overview of the FitnessGram Pacer Test procedures

## Key Points
- The Pacer Test is a multi-stage aerobic capacity assessment that increases in difficulty over time
- Test duration: 20 meters per lap, begins in 30 seconds
- Participants must line up at the starting point
- Running pace starts slow but accelerates each minute following an audible signal
- Participants must complete one lap per signal
- Requirements:
  - Run in a straight line
  - Continue running as long as possible
- Test termination: Ends after the second failed lap completion before the signal
- Test initiation: Begins on the command "start" following "On your mark, get ready"
