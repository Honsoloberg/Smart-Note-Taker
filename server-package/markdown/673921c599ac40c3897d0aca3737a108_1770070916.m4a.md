# Meeting Summary: Fitness Gram-Pacer Test Instructions

## Overview
The Fitness Gram-Pacer Test is a multi-stage aerobic capacity assessment that increases in difficulty over time.

## Key Instructions

### Test Setup
- **Test Type**: 20-meter pacer test
- **Start Time**: Begins in 30 seconds
- **Starting Position**: Line up at the start line

### Test Execution
- **Pacing**: Running speed starts slowly and increases each minute
- **Lap Completion**: One lap should be completed each time the signal sounds
- **Running Form**: Participants must run in a straight line
- **Duration**: Continue running as long as possible

### Test Completion
- **Failure Condition**: Test ends after the second failed lap completion
- **Start Command**: Test begins on the word 'start'
- **Start Sequence**: 'On your mark, get ready, start'
