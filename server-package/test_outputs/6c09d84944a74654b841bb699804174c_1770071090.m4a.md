# Meeting Summary

## Topic Discussed
- Overview of the FitnessGram Pacer Test protocol

## Key Points Covered
- **Test Nature**: Multi-stage aerobic capacity assessment with progressive difficulty
- **Preparation**: 30-second countdown before test initiation
- **Procedure Details**:
  - 20-meter distance
  - Gradual speed increase each minute
  - Audio signals indicate lap completion timing
- **Execution Guidelines**:
  - Run in straight lines
  - Continue running as long as possible
- **Termination Criteria**: Test ends after second consecutive lap failure
- **Start Command**: Sequence: 'On your mark, get ready, start'
